# Sales Assistant

Настольная CRM для Windows для активных B2B-продаж: собственная база предприятий,
поиск потенциальных клиентов, история взаимодействий, задачи, документы,
опциональное ИИ-обогащение карточек.

Разрабатывается как часть портфеля [Libra Works](#).

> **Статус: в активной разработке (ранняя стадия).** Публичного релиза ещё нет,
> ядро CRM ещё не полностью стабилизировано — см. [раздел «Дорожная карта»](#дорожная-карта).

---

## Возможности (целевые)

- Карточка предприятия: контакты, история взаимодействий, задачи, документы
- Лента истории — append-only, ничего не удаляется физически
- Поиск предприятий через [Checko](https://checko.ru) с последующим импортом в базу
- Теги и пользовательские поля на карточках компаний/контактов
- Опциональный модуль сделок (Deals) — включается по необходимости
- Опциональное ИИ-обогащение карточек: поиск сайта компании, контактов и соцсетей
- Установка без прав администратора, portable-режим без инсталлятора

Подробное архитектурное описание — в [`docs/architecture.md`](docs/architecture.md).

## Установка (для разработки)

```powershell
git clone https://github.com/vasinman-alt/SalesAssistant.git
cd SalesAssistant
python -m venv .venv
.venv\Scripts\activate
pip install -e .
```

Применить миграции и создать базу:

```powershell
alembic upgrade head
```

Запустить приложение:

```powershell
python -m sales_assistant
```

По умолчанию приложение работает в **portable-режиме** — данные (`sales.db`,
документы, кэш) хранятся в папке `data/` рядом с кодом. Подробнее о portable- и
установленном режиме — в [`docs/architecture.md`](docs/architecture.md#3-установка-и-хранение-данных).

## Настройка

При первом запуске потребуется указать API-ключ [Checko](https://checko.ru) в
настройках приложения — он нужен для поиска предприятий по открытым данным.

## Разработка

Проект использует слоистую архитектуру: `UI → Service → Repository → SQLite`.
UI-слой не должен обращаться к БД напрямую — только через сервисы. Подробности
и обоснование — в [`docs/architecture.md`](docs/architecture.md).

Тесты:

```powershell
pytest
```
